# Art sources

Both atlases are original procedural SVG pixel art authored for this repository under the MIT license.

- `environment-tiles.svg` is a 5 × 1 atlas of 32 px tiles in this order: grass, soil, path, bush, water.
- `rabbit-sprites.svg` is a 3 × 1 atlas of 32 px frames in this order: idle, hop, eat.

Replace either file with an asset of identical frame dimensions (or update the source-region constants in `src/main.ts`). Environment art and rabbit art are deliberately separate; neither file contains game state or rules.
